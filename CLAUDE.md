# CLAUDE.md

Standing instructions for Claude Code when working in this repository.

## Code comments

All code written in this project — for every file, going forward, not just the current task — must include clear comments:

- A short comment above each function explaining what it does.
- Inline comments for any non-obvious logic, such as RLS-dependent (Row Level Security) queries or role-based conditionals.

This applies regardless of language or file type.
